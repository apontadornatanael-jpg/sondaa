# 🚜 Boletim de Sondagem Rotativa - Streamlit App

Aplicativo interativo para preenchimento de boletins diários de sondagem e exportação em Excel.

## 🛠️ Tecnologias
- Streamlit
- Pandas
- OpenPyXL

## 🚀 Como Executar
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o app: `streamlit run app_sondagem.py`
